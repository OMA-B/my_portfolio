MICHAEL ADESHINA — PORTFOLIO PROJECT IMAGE PROMPTS
================================================

Use these prompts with an image generator to create editorial case-study artwork for the portfolio. The images should look like intentional product/engineering visuals, not literal screenshots unless you replace them with real screenshots later.

Global direction for every project:
- Premium software-engineering case study
- Dark navy / near-black background
- Electric cyan data and system accents
- Warm amber highlights for human/workflow context
- Editorial grid, precise lines, generous negative space
- Subtle depth, tactile glass panels, restrained glow
- Realistic interface fragments or diagrammatic architecture
- No watermark, no logo misuse, no unreadable fake UI text, no random charts
- 16:9 landscape, 2400x1350 or higher
- Leave clean areas where a title or project label can be overlaid later
